# Keyboard shortcuts

On macOS, use Cmd for Ctrl. Single-key shortcuts don't work while you're typing in a field. The command palette (Ctrl+Shift+P) lists every command, with its shortcut if it has one.

## Files

| Keys | Command |
|---|---|
| Ctrl+N | New room… |
| Ctrl+O | Open… |
| Ctrl+S | Save |
| Ctrl+Shift+S | Save as… |
| Ctrl+E | Compile and export .roo… |
| Ctrl+, | Preferences… |

## Editing

| Keys | Command |
|---|---|
| Ctrl+Z | Undo |
| Ctrl+Y, Ctrl+Shift+Z | Redo |
| Ctrl+C | Copy |
| Ctrl+X | Cut |
| Ctrl+V | Paste at cursor |
| Ctrl+D | Duplicate |
| Delete, Backspace | Delete |
| Ctrl+A | Select all (in the current mode) |
| Esc | Back to the Select tool; with Select already active, clear the selection |

## Modes and tools

| Keys | Command |
|---|---|
| T | Things mode |
| V | Vertices mode |
| L | Linedefs mode |
| S | Sectors mode |
| Tab, Shift+Tab | Next mode, previous mode |
| Q | Select tool |
| D | Draw lines |
| R | Rectangle |
| 4 | Polygon |
| 5 | Circle |
| 6 | Torch |
| 7 | Add thing |

## While drawing lines

| Keys | Does |
|---|---|
| Enter | Finish an open line |
| Backspace | Remove the last point |
| Esc | Cancel the line |

## View

| Keys | Command |
|---|---|
| Ctrl+1 | Map view |
| Ctrl+2 | 3D preview |
| Ctrl+3 | Split view |
| F | Fit room |
| C | Center on selection |
| + , − | Zoom in, zoom out |
| G, Shift+G | Bigger grid, smaller grid |
| H | Show grid |
| Shift+H | Snap to grid |
| K | Show Kod placements |
| Shift+W | Walk in 3D (start or stop) |
| Ctrl+Shift+P, F1 | Command palette… |

## Mouse

| Mouse | Does |
|---|---|
| Wheel | Zoom the map (or the 3D view) |
| Middle-drag, or Space + drag | Pan the map |
| Right-click | The right-click menu |
| Left-drag in 3D | Turn the view |
| Right-drag in 3D | Slide the view |

## Walk mode

| Keys | Does |
|---|---|
| W / S, ↑ / ↓ | Walk forward and back |
| A / D | Step left and right |
| ← / → | Turn |
| Shift | Run |
| Page Up, Page Down | Look up, look down |
| Home | Look straight ahead |
| Esc | Stop walking |

## Vertices

| Keys | Command |
|---|---|
| Ins | Add linedefs between the selected vertices, or with fewer than two selected, add a vertex at the cursor |
| Shift+Ins | Add linedefs and close the loop |
| M | Merge vertices into one |

## Linedefs

| Keys | Command |
|---|---|
| X | Split linedef (add vertex) |
| Shift+F | Flip linedef |

## Search and checks

| Keys | Command |
|---|---|
| Ctrl+F | Find / change… |
| Ctrl+J | Jump to object… |
| N, P | Next object, previous object |
| F9 | Run all checks |
